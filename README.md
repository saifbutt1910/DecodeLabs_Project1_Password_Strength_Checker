# Password Strength Checker

A simple cybersecurity project developed as part of the DecodeLabs Cyber Security Internship.

## Project Goal

The program checks whether a password is Weak, Medium or Strong based on basic security requirements.

## Security Checks

The program checks:

- Password length (8 or more characters)
- Uppercase letters
- Numbers
- Symbols
- Commonly used passwords
- Empty or whitespace-only passwords

## Strength Levels

- **Weak:** 0–1 security checks passed
- **Medium:** 2–3 security checks passed
- **Strong:** All 4 security checks passed

## Technologies

- Python
- String Handling
- Conditional Logic
